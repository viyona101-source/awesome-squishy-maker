# Awesome Squishy Maker

A cute browser game for making and playing with squishies, with daisies all over the page.

- **Make a squishy:** choose a Squishy Dumpling or a Needoh, pick a color, add glitter, swipe up to wrap it, then give it a face (dumpling) or a word (Needoh).
- **Play:** squish, stretch, bounce and swirl the glitter, plus mini-games like Mystery Squishy with 10 mystery boxes.
- **My collection:** save your favorite squishies.
- **Talk:** chat with your squishy.

## Play it

Open `index.html` in any web browser, or turn on GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main` / root). The game will then be at
`https://viyona101-source.github.io/awesome-squishy-maker/`.

## Notes

When the game runs outside Claude (for example on GitHub Pages):

- The collection is saved in the browser on that device.
- Talk uses simple built-in squishy replies instead of Claude.
